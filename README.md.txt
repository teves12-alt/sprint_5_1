# Автотесты для Stellar Burgers

Набор тестов для проверки веб‑приложения Stellar Burgers с использованием Selenium.

## Функционал, который покрывают тесты:
- регистрация пользователя с валидацией данных;
- разные способы входа в аккаунт;
- навигация по интерфейсу;
- работа разделов конструктора бургеров.

## Установка и запуск

1. Установите зависимости: `pip install selenium`.
2. Скачайте ChromeDriver и GeckoDriver (для Firefox) и добавьте их в PATH.
3. Запустите тесты: `python -m unittest discover -s tests`.
